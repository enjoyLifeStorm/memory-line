# 小树苗练字记忆曲线工具 (Memory-Line)

> 专为幼儿园大班至小学一年级幼小衔接儿童设计的全场景练字与记忆曲线复习系统。

---

## 🌟 核心特性

1. **幼小衔接四大品类全覆盖**：
   - **基础汉字**：标准米字格/田字格，十字虚线与对角线辅助观察间架重心；
   - **阿拉伯数字 (0~9)**：标准 2:3 宽高比日字格，带有横向腰线虚线与 7° 倾斜导引，专治儿童数字倒写与比例失调；
   - **汉语拼音**：标准四线三格，中间格柔和高亮，帮助分清 `b/d/p/q` 等上下出头规则；
   - **英文字母**：大小写标准手写体占位。

2. **多模态发音配置中心 (Voice Provider Hub)**：
   - **百度语音 (Baidu TTS)**：支持百度标准中文语音合成，声音自然柔和；
   - **网易有道词典发音 (Youdao Voice)**：支持汉字、拼音和英语标准原声音频；
   - **系统原生离线语音 (Web Speech API)**：无需网络、免配置，支持 0.75x 慢速跟读；
   - **自定义 API 模板 (Custom TTS)**：支持在后台配置自定义第三方语音合成 URL 模板；
   - 系统支持一键切换生效引擎、在线试听测试，配置持久化于 H2 数据库。

3. **高保真动态运笔笔顺演示**：
   - 纯矢量 SVG 路径插值动画，带有笔尖红点光晕光标动态循迹；
   - 伴随生动的儿歌口诀（如“2像小鸭水上漂，半圆弯弯平底横”）与运笔要领同步引导。

4. **具体公历复习日历 (Calendar Schedule)**：
   - 废弃抽象的“Day+N”，直接映射为真实公历日期（YYYY-MM-DD）；
   - 直观查看历史哪天练了多少个、未来哪天有到期复习任务，避免复习扎堆。

5. **SM-2 改良版自适应遗忘调度**：
   - 提供 3 星反馈机制（需重练 / 良好 / 熟练）；
   - 太难则安排次日重新强化，熟练则顺延阶梯复习周期；
   - 配合小树成长与墨汁能量激励体系。

---

## 🛠️ 技术架构

- **后端**：Java 17, Spring Boot 2.7.18, Spring Data JPA, Lombok
- **数据库**：嵌入式 H2 Database (File-based: `./temp/data/memory_line`)
- **日志**：Logback 异步滚动日志 (限制 300MB，保留 60 天)
- **前端**：响应式现代 HTML5 / CSS3 / ES6+（前后端一体打包）

## 🚀 快速启动

### 方式一：Maven 编译并运行
```bash
# 1. 编译打包
mvn clean package

# 2. 启动服务
java -jar target/memory-line-1.0.0.jar
```

### 方式二：访问服务
- **系统主页**：[http://localhost:8088/](http://localhost:8088/)
- **H2 控制台**：[http://localhost:8088/h2-console](http://localhost:8088/h2-console)
  - JDBC URL: `jdbc:h2:file:./temp/data/memory_line`
  - 用户名: `sa`，密码为空

## 数字选择与加练

- 点击「数字(0-9)」，可以直接点选 0–9 任意数字。
- 「今日学习」一键开始或继续，先复习再新学；每天新学支持 5、10、20、50 个，开始后固定清单，完成后可主动再学 5 个。
- 「自由选练」展示完整题库，未到复习日期的内容也能加练。
- 同一天重复练习会保存记录，但不会重复提升记忆阶段。
- 日期使用当天上海时间；每日任务及打卡不再固定日期。
- 升级时自动补齐缺失数字，保留已有卡片进度和练习历史。

本地编译：`mvn clean verify`。上传 JAR 后，使用 `Dockerfile.runtime` 与 `docker-compose.override.yml` 构建运行镜像，避免在服务器下载 Maven 依赖。

## 一年级基础分级学习与移动端

题库已扩展为汉字100个、拼音87张（含四声练习）、英文字母26组大小写和数字0–9，共223张卡片。新学按难度和学习顺序推进，支持按科目、单元选练与查看已学进度。手机使用上下布局，平板左右分栏，触控按钮至少44px。

内容编排、数据生成和升级规则见 [CURRICULUM.md](CURRICULUM.md)。汉字笔顺来源及许可见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。

## 书写演示与运笔要领朗读

- 格线、笔画与红点在同一 SVG 坐标系内绘制，保持字形比例；横竖屏切换不会让红点脱离笔画。
- 播放时以灰色轮廓辅助观察，并高亮当前笔画的要领。
- 运笔要领可全部朗读，也可点击每一笔右侧的喇叭单独朗读；再次点击可停止，切换卡片会取消旧声音。
- 中文口诀与要领始终以中文朗读；网络语音失败时回退到设备语音。


## 每日学习流程

打开首页查看今日复习和新学数量，点击「开始今天的学习」。到期复习覆盖各科，家长设置中的科目、单元用于选择新学内容；默认每天新学5个。当天清单保存在服务端数据库，刷新或换设备可以继续，全站沿用现有的一份学习进度。

跟读、观看演示并在纸上练习后，选择「还要帮忙 / 提醒一下会 / 自己会了」，才记录完成并安排下一次复习。重复练同一张只计一次清单完成；需要帮助的卡次日再复习。中途可返回首页休息，未完成清单保留。

完成后显示结束页。主动「再学5个」或自由练习单独统计，不改变原每日目标。当天开始后更改家长设置用于下一天；当日加练沿用已保存的科目和单元。手机练习页底部固定反馈按钮，进度显示在上方。

新增接口：GET /api/cards/daily-plan（只读预览或继续状态）、POST /api/cards/daily-plan/start（幂等固定当天清单）、POST /api/cards/daily-plan/extra（完成当前清单后加练）。日期以 Asia/Shanghai 为准，历史清单保留于 tb_daily_plan。


## 图像联想与主动回想

第一批为28个基础汉字和0–9数字提供自制SVG插图、一句话记忆联想和中文朗读（static/memory-aids.json，可由tools/generate_memory_aids.py重新生成）。联想提示用于理解意思、观察形状，不作为字源解释。其余卡片也可使用藏字、听读音、结构提示和展开对照。

新学卡先看图、听提示、看演示并在纸上跟写，再点击「藏起范字，自己写」，试写后「展开对照」。今日复习默认藏起答案，听读音后尝试写。藏字时范字、拼音文字、图像故事、口诀、笔顺和题库列表一并隐藏；需要时依次请求图像、结构提示。家长按实际回想结果反馈，系统不自动识别纸面书写。

新版本开始的每日计划，已学新卡在间隔两张不同内容后穿插一次回想；未到间隔的最后几张在原清单结束后回想。回想结果单独保存在tb_recall_result，幂等提交，不重复增加打卡次数、每日目标或记忆阶段。需帮助或使用提示的回想安排次日再复习。开始前已有的每日计划不强行补回想任务，保留其原本完成状态。回想进度保存在服务器，刷新或换设备可继续。
