# 小孩练字记忆曲线工具需求规格说明书 (req.md)

## 1. 项目背景与目标
汉字书写与认读具有鲜明的“遗忘快、间架结构易走样、笔顺易混淆”等特点。特别是在**幼儿园大班到小学一年级的“幼小衔接”关键期**，5~6 岁儿童面临从随意涂鸦到规范书写的跨越。此阶段不仅需要学习基础汉字，还必须系统攻克**阿拉伯数字（0~9）**、**汉语拼音（声母/韵母/整体认读）**以及**26个英文字母**的规范书写。
幼儿普遍面临“数字镜像反写（如2、3、7反向）”、“拼音 b/d/p/q 混淆”、“四线三格占位错误”等认知难点。

本项目旨在为少儿（特别是幼小衔接儿童）打造一套**涵盖汉字（米字格）、数字（日字格）、拼音（四线三格）、英文字母（四线三格）的全场景记忆曲线练字与日历工具**。
在第一阶段全栈服务与 H2 数据库持久化落地后，系统全面升级**第二阶段全场景体验闭环**，涵盖：
1. **A4 可打印字帖生成（纸质实操，保护视力）**；
2. **屏幕交互手写/描红临摹画板（Canvas 触屏书写）**；
3. **Web Audio 原生激励音效与书法小树养成体系**；
4. **易混淆镜像字符专项对比辨析模式（b vs d、p vs q、2 vs 3）**；
5. **家长自定义生字词录入与灵活扩库**；
6. **记忆日历点击下钻日程卡片与负荷预警**；
7. **数据一键备份与恢复（JSON 格式）**；
8. **PWA 移动端与平板全屏桌面轻应用支持**。

---

## 2. 核心用户角色
- **幼小衔接儿童（5~6岁，主要练习者）**：
  - 核心需求：图文并茂、生动儿歌口诀引导、书写格线清晰、标准发音慢速跟读、笔顺动画跟写、屏幕描红动手写、易懂的星星激励与小树养成。
- **家长/幼小衔接辅导老师（指导监督者）**：
  - 核心需求：一键生成 A4 纸质练习字帖打印、分品类安排计划、追踪复习日历、针对性纠正镜像倒笔画和占格偏差、自由录入新字、备份学习进度。

## 3. 功能需求矩阵

### 3.1 多品类书写训练与专用书写格体系
1. **多学科品类支持**：
   - **基础汉字**：独体字与笔画基础（如：一、二、三、人、口、手、日、月、水、火、春、永）。
   - **阿拉伯数字 (0~9)**：重点攻克数字封口、圆弧角度与防镜像反写。
   - **汉语拼音**：声母（b, p, m, f, d, t, n, l...）、单韵母（a, o, e, i, u, ü）等。
   - **英文字母 (Aa ~ Zz)**：大写英文字母与小写英文字母标准手写体。
2. **场景化专用书写格自适应**：
   - **米字格/田字格**：服务于汉字，带虚线十字中线与对角线。
   - **数字日字格（田字格半格）**：标准幼小衔接日字格，带有横向腰线虚线与 7° 倾斜参考线，指导数字右上起笔、左下斜收与占格比例。
   - **四线三格**：标准拼音/英文书写格，中格采用温和浅黄高亮，直观指导“有头占上格、有尾占下格、没头没尾占中格”。
3. **幼小衔接儿歌书写口诀库**：
   - 针对数字与拼音字母提供经典童谣（如：“1像铅笔细又长”、“2像小鸭水上漂”、“3像耳朵听声音”、“右下半圆 b b b，右上半圆 p p p”）。

### 3.2 A4 规范字帖一键生成与打印 (A4 Practice Sheet Export)
1. **纸质实操与视力保护**：
   - 支持一键将“今日待练/待复习清单”或“全部分类字符”生成标准的 A4 练习字帖并调起系统打印；
2. **专业排版规范**：
   - 顶部包含：练习日期、姓名横线、完成评价（星级打分）；
   - 字符行排版：
     - **第 1 格**：示范标准黑字与拼音；
     - **第 2~4 格**：浅灰色（#d5d5d5）虚线或轮廓描红字（供幼儿使用铅笔握笔描红）；
     - **第 5~8 格**：对应的标准米字格/日字格/四线三格空白格（供独立临摹与书写）。

### 3.3 屏幕交互手写/描红板 (Canvas Interactive Pad)
1. **触屏/鼠标互动临摹**：
   - 在书写格上方叠置高性能 HTML5 Canvas 画板；
   - 孩子可用手指、触控笔或鼠标直接在格子上跟着动画或底图写字；
2. **书写辅助控制**：
   - **底字开关**：一键切换“显示描红底字 / 隐藏底字（自我测试）”；
   - **一键清空**：清除当次书写笔画重新练习；
   - **笔刷平滑**：支持平滑线条插值，颜色为墨汁深黑，粗细适中。

### 3.4 原生激励动效与 Web Audio 音效系统 (Audio & Motivation System)
1. **纯原生合成音效 (零外部网络依赖)**：
   - 基于浏览器 Web Audio API 振荡器与增益节点合成：
     - 打卡成功 / 3星熟练：清脆明亮的“叮咚！”八度琴音；
     - 徽章解锁：欢快的琶音激励旋律；
2. **小树苗与墨水能量成长体系**：
   - 每次打卡获得墨水能量，右下角小树苗经历“🌱 幼芽 → 🌿 抽枝 → 🌲 成树”三阶段动态生机动画；
   - 连续打卡 3 天、7 天、30 天自动点亮“勤学之星”、“间架小能手”勋章。

### 3.5 易混淆镜像字符专项辨析 (Confusion Comparison Mode)
1. **针对幼小衔接核心痛点**：
   - 专治 `b ↔ d`、`p ↔ q`、数字 `2 ↔ 3` 等儿童大脑发育期常见的镜像反写混淆；
2. **并排对比与动态高亮**：
   - 一键打开【🪞 易混淆对比】弹窗，双格并排展示；
   - 动态高亮关键区别特征（如高亮“b 的半圆在右下，d 的半圆在左下”）；
   - 独立点播各自的口诀童谣与辨析技巧。

### 3.6 家长自定义生字录入与字库扩充 (Custom Character Creation)
1. **灵活扩充字库**：
   - 提供【➕ 添加生字】弹窗，家长可录入汉字、数字、拼音或字母，指定拼音与口诀；
   - 提交后自动通过 REST API 写入 H2 数据库，立即进入艾宾浩斯练习队列；
2. **支持智能补齐**：
   - 自动推导标准书写格类型（汉字默认米字格、数字日字格、拼音/字母四线三格）。

### 3.7 记忆日历日程下钻与负荷预警 (Calendar Details & Load Balance)
1. **点击下钻明细**：
   - 点击日历上的任意日期格，弹出当天详细日程卡片；
   - 清晰展示当天历史已练字符、计划复习字符及星级反馈；
2. **任务负荷预警**：
   - 当单日计划复习超过 10 个字符时，标注橙色预警，提醒家长合理控制单日练习量。

### 3.8 数据安全备份与一键还原 (Backup & Restore)
1. **一键导出备份**：
   - 支持将所有卡片、复习记录及发音配置一键打包导出为结构化 JSON 文件并自动下载到本地；
2. **一键上传恢复**：
   - 支持导入之前备份的 JSON 文件，自动校验并持久化写入后端数据库，保障家庭学习数据零丢失。

### 3.9 PWA 移动端与平板全屏桌面轻应用 (PWA Support)
1. **全屏沉浸体验**：
   - 提供 Web App Manifest 与 Service Worker 支持，支持在 iPad、Android 平板或手机上“添加到主屏幕”；
   - 启动后自动隐藏浏览器地址栏与底部导航栏，变身儿童专用全屏字帖应用。

## 4. 业务流程与交互规范
1. **主工作台**：
   - 一进入网页即展示完整的今日练字工作台与字符列表，字形、拼音、口诀与书写大格完全常驻可见；
   - 点击【✍️ 屏幕描红】即可唤起手写画板用手指书写；
   - 点击【🖨️ 打印字帖】一键生成标准化 A4 纸质描红字帖；
   - 点击【🪞 易混对比】即刻学习 b/d、p/q 辨析口诀；
   - 点击打分按钮触发愉悦音效，系统自动计算下次公历复习日期并切换到下一个字。
2. **日历看板**：
   - 查看整月复习安排，点击任意日期查看当天具体任务清单。
3. **配置与管理中心**：
   - 随时切换发音引擎、录入新字、备份或还原数据。

3. 手写板触控灵敏、支持底字描红与一键擦除。
4. 严格遵守开发规约：UTF-8 编码、类注释 `@author congwu.lei`、无 `@since`、使用 `autoconfig` 包名、使用 yaml、滚动异步 logback、`mvn clean` + `mvn package` 构建验证生成 jar 包。
