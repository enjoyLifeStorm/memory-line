# 小孩练字记忆曲线工具需求规格说明书 (req.md)

## 1. 项目背景与目标
汉字书写与认读具有鲜明的“遗忘快、间架结构易走样、笔顺易混淆”等特点。特别是在**幼儿园大班到小学一年级的“幼小衔接”关键期**，5~6 岁儿童面临从随意涂鸦到规范书写的跨越。此阶段不仅需要学习基础汉字，还必须系统攻克**阿拉伯数字（0~9）**、**汉语拼音（声母/韵母/整体认读）**以及**26个英文字母**的规范书写。
幼儿普遍面临“数字镜像反写（如2、3、7反向）”、“拼音 b/d/p/q 混淆”、“四线三格占位错误”等认知难点。

本项目旨在为少儿（特别是幼小衔接儿童）打造一套**涵盖汉字（米字格）、数字（日字格）、拼音（四线三格）、英文字母（四线三格）的全场景记忆曲线练字与日历工具**。
在完成了纯前端交互原型验证后，本项目正式进入**全栈落地阶段**，引入 Spring Boot 后端驱动与 H2 嵌入式数据库进行持久化，并构建灵活的**多源发音配置中心（支持百度TTS、有道发音、自定义API源及浏览器离线原生发声）**，帮助幼儿和家长获得低延迟、高可靠、可定制发音的系统化书写抗遗忘训练体验。

---

## 2. 核心用户角色
- **幼小衔接儿童（5~6岁，主要练习者）**：
  - 核心需求：图文并茂、生动儿歌口诀引导、书写格线清晰、标准发音慢速跟读、笔顺动画跟写、易懂的星星激励与小树养成。
- **家长/幼小衔接辅导老师（指导监督者）**：
  - 核心需求：分品类（汉字/数字/拼音/字母）安排计划、追踪复习日历、针对性纠正镜像倒笔画和占格偏差、自由配置高品质发音源（如百度语音、真人标准发音库）。

---

## 3. 功能需求矩阵

### 3.1 多品类书写训练与专用书写格体系
1. **多学科品类支持**：
   - **基础汉字**：独体字与笔画基础（如：一、二、三、人、口、手、日、月、水、火、春、永）。
   - **阿拉伯数字 (0~9)**：重点攻克数字封口、圆弧角度与防镜像反写。
   - **汉语拼音**：声母（b, p, m, f, d, t, n, l...）、单韵母（a, o, e, i, u, ü）等。
   - **英文字母 (Aa ~ Zz)**：大写英文字母与小写英文字母标准手写体。
2. **场景化专用书写格自适应**：
   - **米字格/田字格**：服务于汉字，带虚线十字中线与对角线。
   - **数字日字格（田字格半格）**：标准幼小衔接日字格，带有横向腰线虚线与 7° 倾斜参考线，指导数字右上起笔、左下斜收与占格比例。
   - **四线三格**：标准拼音/英文书写格，中格采用温和浅黄高亮，直观指导“有头占上格、有尾占下格、没头没尾占中格”。
3. **幼小衔接儿歌书写口诀库**：
   - 针对数字与拼音字母提供经典童谣（如：“1像铅笔细又长”、“2像小鸭水上漂”、“3像耳朵听声音”、“右下半圆 b b b，右上半圆 p p p”）。

### 3.2 多源发音库配置中心 (Voice & Audio Provider Hub)
针对儿童跟读纠音需求，提供灵活、可切换的多来源发音库配置：
1. **支持的发音源类型**：
   - **浏览器原生离线合成 (Web Speech API)**：零依赖、零成本、无需联网即可发声，支持 0.75x 慢速播放。
   - **百度语音 TTS 开放源 (Baidu TTS)**：支持百度翻译语音合成或百度智能云 TTS API，声音自然圆润，发音标准。
   - **网易有道词典标准音源 (Youdao Voice)**：支持汉字、拼音和英语标准真人音标发音。
   - **自定义发音源 API 模板 (Custom TTS URL)**：支持用户配置自定义 URL 模板（如 `https://custom-tts.example.com/api?text={text}&spd={speed}`），满足私有化部署或第三方商业 TTS 需求。
2. **发音配置管理面板**：
   - 家长可在系统设置中一键切换“当前生效发音引擎”。
   - 支持在线试听测试（输入任意文字即时试听播放效果）。
   - 支持配置发音语速（0.5x~1.5x）、音调及音色标识。
   - 配置数据持久化存储于后端数据库中，系统重启后配置不丢失。

### 3.3 动态书写演示与运笔笔顺引擎 (Stroke Animation Demo)
针对幼儿“看不懂静态字如何下笔、容易倒笔画、起笔位置错误”的痛点，系统提供高保真动态书写演示：
1. **动态运笔播放 (Play & Replay)**：
   - 点击【播放书写演示】，系统自动在米字格/日字格/四线三格中，按照规范笔顺动态插值划出每一笔。
   - 笔尖附带高亮导引光标（笔尖红点光晕），清晰展现起笔、行笔、转折与收笔全过程。
2. **笔顺分解与音画同步**：
   - 运笔演示时，同步展示当前笔画名称（如“第一笔：右上圆弧；第二笔：平底横”）。
   - 支持与发声系统协同，一边动态画线一边朗读运笔要领，帮助幼儿形成空间动觉记忆。

### 3.4 练字记忆日历与日程看板 (Calendar Schedule)
为了解决相对周期（如 Day+0, Day+1, Day+4）过于抽象的问题，工具全面引入**具体公历日期映射**与**月度记忆日历看板**：
1. **记忆日历总览 (Monthly Calendar)**：
   - **过往历史轨迹**：直观展示过去每一天的打卡状态、练了多少个字、评价星级。
   - **未来复习负荷预测**：根据已学卡片的艾宾浩斯推进节点，在未来的日期格子上标记待复习字符数量，帮助家长提前合理安排复习节奏。
   - **日期下钻交互**：点击日历上任一日期，即可在侧边抽屉中即时列出该日具体的练习字符清单。
2. **字符全周期真实日期时间轴**：
   - 每个字符记录精确日期时间线（如“初学: 10月15日”、“第1次复习: 10月16日”、“第2次复习: 10月18日”、“第3次复习: 10月22日”等）。

### 3.5 闭环反馈与自适应记忆曲线 (SM-2 Modified)
1. **3星即时打分反馈机制**：
   - ★☆☆ 需重练（太难/写错）：笔顺倒写、占格错误。系统重置为 Stage 1，安排次日重新强化。
   - ★★☆ 良好（一般）：能写出大致形状，细节稍显生硬。保持常规艾宾浩斯阶梯间隔。
   - ★★★ 熟练（太棒了）：笔画端正，一气呵成。系统增加熟练度因子，适度延长复习间隔。
2. **激励体系**：
   - 每次练习打卡产生墨汁能量，灌溉书法小树成长；连续打卡天数统计与勋章。

### 3.6 全栈持久化与架构升级 (Full-Stack & Persistence)
1. **Spring Boot 后端服务**：
   - 提供稳定高效的 RESTful API，统一管理练习卡片、复习记录、日历调度及发音源配置。
2. **H2 嵌入式数据库**：
   - 采用 H2 Database 本地持久化文件存储，零运维、免安装外部数据库软件；
   - 包含 H2 Web 控制台（Console），方便排查与数据审查；
   - 预置常用幼小衔接数字（0~9）、拼音、英文字母及常用汉字基础数据。

---

## 4. 业务流程与交互规范
1. **启动与主界面**：
   - 系统自动聚合今日需练习任务（今日新学 + 到期复习）。
2. **多模式练习与演示**：
   - 点击发音：调用当前配置的发音引擎（百度/有道/自定义/原生）发音；
   - 播放演示：调用 SVG 笔顺引擎动态走笔；
   - 练习打分：选择星级反馈，后端实时计算下一次复习公历日期并持久化写入 H2 数据库。
3. **发音配置调整**：
   - 点击导航栏【发音配置】，弹出配置面板，可切换百度TTS、有道、原生引擎，输入参数并即时测试发音，确认后保存生效。

---

## 5. 验收标准
1. 后端使用 Spring Boot 3/2 + H2 数据库构建，完整支持卡片、日志、配置的增删改查与排期计算。
2. 前端完美复现幼小衔接4大品类书写格、发音、笔画演示与日历看板，且与后端 REST API 完整联通。
3. 发音库配置中心可自由切换发音源（百度、有道、自定义、原生），并提供真实试听能力。
4. 严格遵守项目规范：编码 UTF-8、Java 注释作者 `@author congwu.lei`、无 `@since`、使用 `autoconfig` 包名、使用 `yaml` 配置格式、logback 异步滚动日志限制 300MB、`mvn clean` + `mvn package` 构建验证生成 jar 包。
