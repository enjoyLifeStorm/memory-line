学习内容与顺序说明

这套内容用于一年级基础的提前学习和巩固，按基础到进阶自主编排，便于选择合适的起点。它不是某一地区、某一版教材的完整课次目录；实际学习节奏可随学校安排调整。

三个学习路线

  • 汉字 100 个：基础笔画与独体字 → 身体与自然 → 生活观察与颜色数量 → 家庭校园 → 时间方位与四季。同一单元内优先安排笔画较少的字。
  • 拼音 87 张卡：6 张单韵母、24 张四声练习、21 张声母及 y/w、18 张复韵母和鼻韵母、16 张整体认读音节。声母、韵母、整体认读循序推进，先看口型与字形，再练拼读。
  • 英文字母 26 组大小写：直线字形 → 斜线组合 → 曲线字形 → 直曲结合。这是额外的英语启蒙内容，不表示所有学校一年级都要求学习英语。

“已学”表示至少完成过一次打卡，不等于完全掌握。每日任务先复习到期内容，再按学习顺序补充新内容；自由选练可以跨单元巩固。同日加练保留记录，但不重复提升记忆阶段。

读音与书写

拼音使用示例汉字读音辅助辨音，界面会显示所读示例字；有些示例含声母，不应将示例字整音当作韵母本音。声母应读轻短。字母为可编辑的手写路径示意；课堂书写细节以老师示范为准。
